# First Day at the Harbour — 改进版

## 启动
打开 `Assets/261122/Museum_261122_1.unity`，等待编译后进入 Play。
由 FirstDayJourney 添加 HarbourTabletopPrototype，动态生成；无需修改或保存场景。
继续使用原展台绑定的 XRInteractionManager、公共 XR Rig、摄像头和控制器。

## 新流程
START → 以任意顺序阅读 WORK PASS 和 LETTER HOME → 可选自由探索 → FIND WORKPLACE → 选择地点 → REPORT AT 02 → 选择货箱 → LOAD HERE → 家书回顾。
两份文件都需要打开过；不要求探索任何区域。选错保留任务并允许重试。
选择答案和探索是两个不同入口：区域标签播放演示，选择面板提交工作地点。
家书正文固定；报到提示 NEXT MORNING，承接家书里的 Tomorrow。

## 动画与状态
- FERRY：船靠岸、乘客标记走向岸边、船离开。
- CARGO：船靠岸，复用 CargoMotion 演示吊机装货。
- REPAIR：船入维修位、检查标记、几何体扳手摆动、维修完成、船返回。
- 区域演示可任意切换、重复播放，STOP DEMO 可中断。只有完整播放才出现 [SEEN] 标记。
- 同时只运行一个动画协程；每次切换先停止并恢复所有模型。
- 演示不改变任务阶段。任务完成后重播 CARGO 会恢复已装船状态。
- 正式装货期间先完成或 SKIP LIFT，再播放探索演示，避免中断正式操作。
- RESTART 关闭文件和选择面板，停止动画，清空已读/已探索/报到状态，复原所有模型。

## Unity 手动验收清单
1. Play 生成成功，无 Console 异常，其他展品仍可使用。
2. START 后两份文件任意顺序打开/关闭；未读完两份时 FIND WORKPLACE 提醒查线索。
3. 自由点击区域，连续切换 FERRY→REPAIR→CARGO，确认乘客、工具、船、货箱和吊钩无残留。
4. 动画过程中打开文件或 STOP DEMO，应停止演示并还原模型。
5. 选择 FERRY/REPAIR 后可重新看文件、播放演示、重新选择；CARGO 正确后需单独 REPORT。
6. 未探索任何区域也能通过线索判断并完成报到。
7. 正式装货完整播放和 SKIP LIFT 两条路径均能结束；探索演示不能完成任务。
8. 完成后重播 CARGO、打开文件，再检查货箱仍在船上、任务不倒退。
9. 在演示、文件、错误选择、报到、装货、结束各阶段 RESTART，均应返回初始状态。
10. 坐姿、单手射线、鼠标点击；检查字体、遮挡、阅读面板、按钮距离和悬停反馈。
