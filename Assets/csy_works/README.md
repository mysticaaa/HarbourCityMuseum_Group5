# csy_works — 陈思宇工作区

> Module 2: 场景搭建 (Scene Building)
> 个人工作区，避免 Git 冲突。最终成品再合并到共享目录。

## 文件夹结构

| 文件夹 | 用途 |
|--------|------|
| Scenes/ | 个人测试场景、场景备份 |
| Models/ | 从 Sketchfab 下载的或 Maya 自建的 3D 模型 |
| Materials/ | 材质文件 (.mat) |
| Textures/ | PBR 贴图 (albedo, normal, roughness 等) |
| Prefabs/ | 预制体 |
| Scripts/ | 个人测试脚本 (正式脚本放 Assets/Scripts/) |
| Lighting/ | 灯光设置、烘焙数据 |

## 规则

1. 自己的东西放这里，不要动别人的文件夹
2. 要改公共资源 (Assets/Scenes/, Assets/Scripts/ 等) 先在群里沟通
3. 最终测试通过后，把成品挪到对应的共享目录
