二、Tech Stack

| Tool | Purpose |
|------|---------|
| Unity 2022 LTS | Game engine / VR scene |
| Meta Quest 3 | Target headset (via Meta Horizon Link streaming) |
| Maya | 3D model creation |
| C# / VS Code | Scripting |
| Git | Version control |

三、Getting Started

3.1 Clone the repository
bash
git clone https://github.com/mysticaaa/HarbourCityMuseum_Group5.git
cd HarbourCityMuseum_Group5
git checkout dev

3.2 Open in Unity
1. Open Unity Hub
2. Click "Open Project" and select the cloned folder
3. Wait for Unity to import assets and compile (first time may take a few minutes)


3.3 Test with Quest 3
1. Ensure Meta Horizon Link is running
2. Connect Quest 3 via Link
3. Press “Play” in Unity

3.4 Running with Quest3
Downlod the .exe file in Quest3, open it.
