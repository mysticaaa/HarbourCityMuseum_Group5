# 船舱物品交互占位原型

## 机动渔船新版（动力与布局）

停止 Play、等待编译后，点击 `Harbour City Museum > ZZX > Create Motor Fishing Boat Preview`。
该菜单使用旧的 CabinPrototype 作为起点，额外生成 MotorFishingBoatPrototype.prefab 与 MotorFishingBoatPreview.unity，不覆盖旧四件物品资源。
打开 MotorFishingBoatPreview 场景并 Play。左前方新物品为动力操纵杆，右前方为船舱布局模型。

- 操纵杆：点击居中检查，再点击 Operate engine lever。低动力、低速度时选择 Ahead，然后提高 Power；右侧显示档位、动力百分比、模拟速度。
- Neutral 切断推进，速度逐渐下降；换向需减小动力、回空档并等待低速，拒绝操作时显示原因。这是教学交互规则，非特定历史设备操作规程。
- 关闭操纵杆查看后保留动力状态，方便切换船舵。查看船舵后点击 Operate wheel，转向结果取决于当前速度，指南针同步变化；动力为零且速度为零时不原地转向。
- 布局：点击模型，再选择 Helm/work position、Living/seating area、Fishing/work area、Access route、Entrance/exit 高亮对应区域，查看用途说明。关闭后清除高亮。
- R 重置全部物品和动力/航向；Escape 关闭当前检查。

布局位置、区域尺寸和座位数为可配置占位示意，没有历史复原依据。换模型时保持区域 Renderer 引用，正式船型确认后替换区域和说明。
模拟没有发动机转速、惯性水动力或真实航行安全含义；档位和动力演示不作为操作真实船舶的指导。

### 新版验收（实际结果请填写，以下是步骤）

1. Ahead 加动力，确认速度逐渐增加；Neutral 确认速度逐渐下降。
2. 动力未归零时切档应出现提示；回空档低速后 Astern 可选，速度变成负值。
3. 有速度时操舵应改变航向及指南针；停止后不继续原地改变航向。
4. 检查、拖动物品不改变动力或航向；关闭操纵杆后可切换船舵继续操作。
5. 五个布局区域分别高亮，切换和关闭不残留高亮；摄像机保持固定。
6. R 重置动力、速度、航向、展品位置；重新 Play 状态应一致。

## 最新操作：居中检查与操舵

打开已有 CabinPreview，停止 Play 等待编译后再运行。不需要重建生成资源。
所有四件物品默认闲置旋转。点击选择后，物品移至预览摄像机画面中央、按包围范围适配放大，固定摄像机不移动；按住左键在面板外拖动可 360 度检查。
Close / Return 或 Escape 恢复物品原来的位置、比例和朝向。查看模式中不切换物品，先关闭再选另一件。
船舵默认只是查看，点击 Operate wheel 后，左右拖动控制舵角，也可以使用滑块、左右微调和 Centre 回中。
右侧航向示意会随舵角持续改变；指南针指针同步相对船向变化。返回查看或关闭停止模拟转向，保留当前航向；R 或 Reset 重置航向。
航向模型使用简化的舵角与角速度关系，不代表真实船舶动力学；它不移动船体和玩家。展示旋转与模拟航向分开，旋转查看不改变航向。
桌面检查输入由 CabinDesktopPreview 提供；正式 VR 居中观察距离、手柄拖动和世界空间按钮需另行适配并验证。

本节替代下方旧版原位放大、点击关闭和指南针/船舵不旋转的描述。

所有个人源码、说明以及菜单生成的资源都保存在本目录。依赖公共 `InteractableObject`，不修改公共脚本或主场景。

## 第一次使用

1. 等 Unity 编译完成，点击 `Harbour City Museum > ZZX > Create Cabin Prototype Assets`。
2. 在 `Generated` 中生成材质、`CabinPrototype.prefab` 和 `CabinPreview.unity`。已有场景或 Prefab 时跳过生成，避免覆盖个人编辑。
3. 双击预览场景，保存其他场景的未保存修改后再切换。点击 Play，鼠标指向占位物后左键选择，R 重置全部物品。
4. 指南针点击显示说明；方向以世界 +Z 为北。转动指南针对象或指定的 shipHeading 可观察针的相对朝向。
5. 船舵点击打开控制面板，使用滑块或左右微调按钮设置角度；范围 -90 到 +90 度，限位不循环跳转，可回中。只演示舵轮旋转，不模拟航行。
6. 指南针、壁画和椅子点击打开说明并平滑放大，再次点击关闭并恢复。面板可切换放大/恢复；椅子有观察旋转滑块，指南针有演示航向滑块，不移动玩家。Close/Escape 关闭，Reset 恢复单件物品。

## 换模型与集成

- 每件物品根对象保留 CabinExhibit 和名称；把 ReplaceableVisual 换成正式模型，确保模型上或子对象有 Collider。
- 舵轮的 movingPart 指向模型旋转轴，wheelAxis 根据模型设置；指南针的 movingPart 指向针的旋转轴，shipHeading 指向船的朝向对象。
- 将 Prefab 交给场景组放入船舱。用户交互组的 RaycastSelector 可通过公共 InteractableObject 调用悬停和选择。
- CabinDesktopPreview 仅存在于预览场景实例；接入公共射线时不要同时启用两套鼠标输入。
- OnGUI 面板仅是桌面原型说明，不是 VR 最终 UI。VR 集成需换成世界空间 Canvas，并接入团队按钮输入。
- 所有介绍均为占位解释；正式内容需注明来源，不把模拟指南针和舵轮表现作为历史事实。
- 本原型没有完成真实抓取、坐姿传送、船体运动、音频或进度计分。

## 验收

- 闲置展示：壁画与椅子默认在无操作 3 秒后绕本地 Y 轴以每秒 12 度旋转。指向、选中或打开说明时停止；离开/关闭后等待 3 秒恢复。Inspector 中可调整 Enable Idle Rotation、Idle Delay、Idle Rotation Speed 和 Idle Rotation Axis。指南针与船舵保持功能朝向，不参加展示旋转。正式挂墙壁画可关闭此开关。

- 四件物品都能指向、选择和显示说明；切换选择时旧说明关闭。
- 舵轮多次点击不会超出角度限制，R 后回到初始角度。
- 转动船朝向时针保持配置北向（默认水平 Y 轴旋转约定）。
- 壁画和椅子反复打开关闭有效；重启 Play 状态恢复。
- 替换模型后重复验收，VR 设备单独验证输入、面板可读性与舒适性。
